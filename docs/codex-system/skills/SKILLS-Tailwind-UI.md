# SKILLS - Tailwind UI Expert

## General UI Style

All UI should feel:

- Modern
- Spacious
- Elegant
- Minimal
- Professional
- Premium

Preferred inspiration:

- Apple
- Stripe
- Vercel
- Linear
- Notion

Avoid:
- Outdated UI
- Crowded layouts
- Tiny spacing
- Excessive borders
- Overly colorful interfaces

---

# Layout Philosophy

Prefer:

- Generous spacing
- Clean alignment
- Consistent padding
- Visual breathing room
- Strong hierarchy

Use:
- max-width containers
- responsive grids
- card-based layouts
- spacing consistency

---

# Tailwind Best Practices

Always:

- Keep class organization clean
- Avoid giant unreadable class strings
- Use reusable patterns
- Use responsive breakpoints properly
- Prefer composition over duplication

Prefer:
- utility consistency
- modular UI sections
- reusable components

---

# Typography

Prefer:

- Clear hierarchy
- Large readable headings
- Comfortable line-height
- Balanced text widths

Avoid:
- Tiny text
- Dense paragraphs
- Overly narrow spacing

---

# Components

Preferred style:

- Rounded corners
- Soft shadows
- Minimal borders
- Modern cards
- Subtle hover effects

Buttons should feel:
- smooth
- modern
- responsive
- premium

---

# Responsive Design

Always prioritize:

- Mobile-first design
- Tablet responsiveness
- Desktop polish

Layouts must:
- collapse gracefully
- maintain spacing
- preserve hierarchy

---

# Animations

Animations should be:

- subtle
- smooth
- purposeful

Avoid:
- excessive motion
- distracting animations
- flashy effects

Preferred:
- fade transitions
- soft hover animations
- smooth transforms

---

# Professional Standards

The final UI should feel like:
- a modern SaaS product
- professionally designed
- production ready

Never generate UI that feels outdated or amateur.
