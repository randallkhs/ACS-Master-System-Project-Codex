# SKILLS - Python GUI Expert

## General Philosophy

Desktop applications must feel:

- Modern
- Clean
- Responsive
- Professional
- Spacious
- Polished

Avoid:
- Outdated desktop UI
- Tiny spacing
- Cluttered layouts
- Generic system-looking apps

---

# Preferred Frameworks

Preferred order:

1. Flet
2. PySide6
3. FastAPI for web backends

Avoid overly outdated GUI frameworks unless necessary.

---

# UI Style

Preferred inspirations:

- Apple
- Notion
- Linear
- Modern SaaS dashboards

Always prioritize:

- Rounded corners
- Proper spacing
- Soft shadows
- Clean typography
- Balanced layouts

---

# Layout Rules

Prefer:

- Modular sections
- Sidebar layouts
- Card-based UI
- Responsive resizing
- Scrollable containers when appropriate

Avoid:
- giant stacked layouts
- oversized toolbars
- crowded controls

---

# Architecture Rules

Always:

- Separate UI from business logic
- Use modular file structure
- Split components into reusable files
- Keep functions focused

Avoid:
- giant app.py files
- spaghetti architecture
- tightly coupled code

---

# Performance Rules

Prefer:

- lazy loading
- reusable components
- optimized rendering
- lightweight UI updates

Avoid:
- unnecessary redraws
- blocking operations on UI thread

---

# UX Rules

The app should feel:

- intuitive
- smooth
- responsive
- polished

Always prioritize:
- visual clarity
- ease of navigation
- clean workflows

---

# Styling

Use:

- consistent spacing
- subtle color palettes
- modern buttons
- smooth hover states
- clean section separation

Animations should be:
- minimal
- smooth
- purposeful

---

# Professional Standards

The application should feel like:
- a premium desktop tool
- professionally designed
- production ready

Never generate desktop UI that feels outdated or amateur.
