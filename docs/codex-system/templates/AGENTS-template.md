# AGENTS.md

## General Philosophy

This project must prioritize:

- Clean architecture
- Modular code structure
- Readability over cleverness
- Production-quality organization
- Maintainability
- Scalability
- Reusable components
- Clear separation of concerns

Avoid:
- Giant monolithic files
- Overengineering
- Unnecessary complexity
- Duplicate code
- Hardcoded values whenever possible

---

# UI / Design Philosophy

The UI must feel:

- Modern
- Minimal
- Professional
- Spacious
- Smooth
- Clean
- Premium

Preferred inspirations:

- Apple
- Stripe
- Linear
- Vercel
- Notion

Always prioritize:

- Good spacing
- Clean typography
- Consistent padding
- Rounded corners
- Subtle shadows
- Visual hierarchy
- Responsive layouts
- Accessibility

Avoid:
- Crowded interfaces
- Tiny spacing
- Outdated styles
- Overly flashy UI
- Excessive colors
- Excessive borders
