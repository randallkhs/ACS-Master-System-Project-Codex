# Category Knowledge Usage Guide

## Purpose

This folder stores reusable technical knowledge by category.

Codex should use this system to avoid unnecessary internet research and reduce token waste.

---

# Main Rule

Codex should only read the category related to the current task.

Do not load unrelated categories.

# Knowledge Lookup Rule

Before internet research:

1. Identify the relevant category.
2. Read only that category's relevant files.
3. If no useful note exists, research online.
4. If useful new information is found, update the category.

---

# Freshness Rule

If a note is older than its expiration window:

- verify online before relying on it
- update Last Verified
- update source links if needed

---

# Efficiency Rule

Do not read all category files unless explicitly requested.

Selective reading is required.
