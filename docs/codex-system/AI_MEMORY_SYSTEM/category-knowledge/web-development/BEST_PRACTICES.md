# Python Development Best Practices

## Core Philosophy

Prioritize:
- modularity
- readability
- maintainability
- scalability
- low coupling

Avoid:
- giant centralized files
- duplicated logic
- tightly coupled systems
- unnecessary complexity

---

# Architecture Preferences

Prefer:
- separated concerns
- reusable modules
- clean folder structures
- service-based architecture

---

# Performance

Avoid:
- blocking UI threads
- unnecessary memory usage
- repeated expensive operations

Prefer:
- caching when appropriate
- worker/thread systems
- lazy loading for heavy systems

---

# AI Workflow Optimization

Prefer:
- compact high-signal documentation
- category-specific memory retrieval
- reusable architecture patterns

Avoid:
- giant memory dumps
- unrelated context loading
