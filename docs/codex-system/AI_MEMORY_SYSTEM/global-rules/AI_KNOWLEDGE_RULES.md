# AI Knowledge Rules

## Purpose

Maintain reusable external AI knowledge efficiently.

Knowledge notes should:
- reduce repeated internet research
- preserve reusable discoveries
- improve long-term AI workflows
- maintain up-to-date technical awareness

---

# Knowledge Categories

Store knowledge in category-specific folders.

Examples:

- web-development
- python-development
- ui-design
- nextjs
- tailwind
- pyside6
- deployment
- ai-workflows
- databases
- performance
- security

Avoid mixing unrelated knowledge categories.

---

# Knowledge Storage Rules

Only store:

- reusable discoveries
- important framework updates
- architecture patterns
- difficult debugging solutions
- performance improvements
- future-useful workflows
- major API changes

Do NOT store:

- trivial findings
- temporary experiments
- repetitive notes
- low-value observations

---

# Freshness Rules

Each knowledge note should include:

- discovery date
- last verification date
- source links
- category tags

---

# Expiration Rules

If knowledge is older than the configured freshness window:

- re-check internet sources
- verify compatibility
- update outdated details if needed

After verification:
- update verification date
- update source links if necessary

---

# Internet Research Rules

Only perform internet re-checks when:

1. No relevant knowledge exists.
2. Existing knowledge is stale.
3. Framework behavior appears changed.
4. Current implementation conflicts with stored knowledge.

Avoid unnecessary repeated research.

---

# Token Optimization Rules

Prefer:
- targeted category retrieval
- compact knowledge notes
- focused summaries

Avoid:
- loading all categories
- giant knowledge databases
- excessive historical notes

---

# Knowledge Reusability

Knowledge should prioritize:
- future projects
- reusable architecture
- repeatable workflows
- scalable best practices

---

# Source Tracking Rules

Whenever possible include:

- source URLs
- documentation references
- framework versions
- API versions

This allows future re-validation.

---

# AI Knowledge Philosophy

The external knowledge system should function as:

- lightweight persistent memory
- reusable technical acceleration
- selective knowledge retrieval

NOT:
- permanent model training
- giant documentation archives
- uncontrolled information dumping
