# Known Issues

## Purpose

Track:
- unresolved bugs
- fragile workflows
- edge cases
- regressions
- dangerous implementation areas

Keep concise and high-signal.

---

# Active Bugs

List:
- current unresolved bugs
- reproduction conditions
- affected systems

Include:
- severity
- impact
- temporary workarounds if available

---

# Fragile Systems

Document systems prone to:
- regressions
- threading problems
- race conditions
- UI freezes
- state inconsistencies

Explain:
- why the area is fragile
- what should be avoided

---

# Edge Cases

Document important edge cases.

Examples:
- corrupted images
- missing JSON fields
- unsupported image formats
- invalid dimensions
- duplicate paths
- interrupted worker operations

Only include meaningful edge cases.

---

# Dangerous Workflows

Document:
- workflows that can break data
- backup-sensitive operations
- replacement-sensitive systems
- expensive processing sequences

---

# Known Limitations

Document:
- current architectural limitations
- unsupported features
- technical constraints
- temporary compromises

---

# Regression Warnings

Document:
- changes likely to break other systems
- systems tightly coupled together
- dangerous refactor areas

---

# Future Investigation Areas

Document:
- unclear bugs
- suspected architectural weaknesses
- possible future optimizations
- systems needing redesign

Keep concise.
